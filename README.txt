S7EVENTEEN · 个人主页

打开：双击「点击打开网页.html」，或在网站根路径打开 index.html。
保留 proto 与 assets 的相对位置，移动时请移动整个文件夹。

首页选择声音后，点击 S7 标记进入小镇。
可进入书店、开发室、暗房、游戏厅、战斗和联系页；按页面提示退出。
核心体验可离线使用；通关 Boss 战后，游戏厅解锁其封面，点击可重新挑战，结束后返回游戏厅。
游戏厅 Boss 挑战从加强Ⅰ开始，获胜后逐级升至加强Ⅲ，并记录击败等级和用时。
15秒内击败加强Ⅲ后，可额外选择满加强挑战：扇斩和闪避各存两次，每4秒恢复一次。
左上角保留加强Ⅲ、满加强的最快记录；满加强解锁后可重新选择两种挑战。
从联系方式返回小镇后，会提示游戏厅上新，可直接前往。
游戏厅 ZATO 的 B 站链接需要联网。
