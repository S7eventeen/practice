怎么打开
    双击最外层的「点击打开网页」—— 它会自己跳进主页。
    （Edge / Chrome 都行。不用联网，不用装任何东西。）

    ★ 主页本体在 proto\ 里面，**别把它单独挪出来**：那些页面是靠相对
      路径互相找的（照片在 ..\assets\ 下），挪出来就全打不开了。
      要移动就整个文件夹一起移动。

打开之后
    1. 先弹一张小卡片问你要不要开声音 —— 点"开声音"或"安静地看"，
       点哪个都行；不点它就一直停在这一屏。
    2. 点页头那个「S7」标记 → 屏幕被斩开 → 露出卡通小镇。
    3. 镇上的房子点得进去：书店 / 开发室 / 暗房 / 游戏厅 / 打 Boss / 联系页。
       每栋房子进去之后，屏幕上都有提示怎么退出。
    4. 游戏厅里那面照片墙上，「ZATO」那张**点得开**（鼠标移上去会变手型），
       点它在浏览器新标签页里打开对应的 B 站视频。其余照片点了没反应。

包里有什么
    点击打开网页.html    入口，双击它
    proto\              页面本体，10 个文件（含全部脚本、样式、音乐）
    assets\             游戏厅那面文字墙用的 33 张照片
    README.txt          本说明

    拔了网线也能完整跑。
